# 过洞大饼

这份文档用于提醒：每次改完代码、刷车或换硬件后，需要定期回归检查的功能点。

## 通用上电检查

- `global_debugger` 中关键设备都在线：遥控/VT、IMU、Pitch、Yaw、摩擦轮、拨弹、升降电机、板间通信、底盘四个轮电机、裁判系统、超电。
- 遥控器 DT7 和 VTM 切换正常；任意一个掉线时控制量能清零，两个都掉线时整车进入下电/离线状态。
- 云台板和底盘板两包 CAN 通信都正常，任意一包掉线时底盘不保留旧速度、旧模式或旧跟随前馈。
- 上电后蜂鸣/灯光状态正常，PC 在线/离线时红绿灯和 UI 显示一致。

## 云台功能

- `global_debugger` 能查到对应设备都在线，Pitch/Yaw 任意一个掉线时 DM 输出进入安全状态。云台电机在下电模式默认红灯，绿灯说明另一个电机掉线了，说明底盘上来的can线可能掉了。
- Pitch/Yaw 前馈闭环响应贴合目标曲线：目标角、实际角、速度、加速度、前馈、PID 输出没有明显滞后、振荡或零点偏置。
- Pitch 重力补偿和摩擦补偿方向正确；低速过零时库仑摩擦前馈不会固定朝一个方向顶。
- Yaw 最短角度回正正常，`return_flag` 触发后底盘暂时退出控制，回到 0.5 度以内后恢复原来的底盘模式。
- Pitch 限幅正确：云台在 `UP` 和 `DOWN` 状态下都不会打到机械限位；下降状态下 Pitch 下限跟随机身姿态变化正常。
- 鼠标控制、滚轮 Pitch、右键自瞄、R/Z/X 模式切换正常；PC 掉线、未识别目标、目标角度大于 70 度时能回到手动控制。
- 自瞄位置控制和前馈控制两种模式都要测：进入、退出、右键松开、PC 数据异常时不出现角度跳变。
- 过洞时发送底盘转向速度前馈，保证底盘与云台同步转向；普通跟随和过洞 `DOWN` 状态下前馈系数分别正确。

## 升降功能

- 升降 2 s 左右完成；上升、下降、半路反向、连续按键都能稳定到位。
- 任意升降动作开始前云台先回正，下降阶段必须等待 `return_flag` 清零，防止磕碰。
- `UP`、`DOWN`、`POWER_DOWN` 三种需求切换后，升降状态机进入正确阶段，完成后电流清零。
- 反馈离线保护正常：老版本检查 TOF 和 M2006，新版本检查编码器和 M2006；反馈恢复后只在允许场景自动续跑。
- 堵转保护正常：高电流且位移不足时能快速停机，不会持续顶机械结构。
- 老版本 TOF：遮挡、突然跳变、空转、方向切换 200 ms 暂停判断、遮挡恢复自动续跑都要测。
- 新版本编码器：编码器不动但电机转、编码器采样不足、编码器方向配置错误时能及时发现。
- 升降位置标定值需要复查：TOF 高/低点、编码器高/低点、传感器到电机方向、到位误差和稳定时间。

## 发射与热量

- 热量控制稳定不超发，注意热量回传延迟和滞后性；`available_shoot` 和实际可发弹量一致。
- 裁判系统热量数据掉线时，不允许因为旧数据误判可继续发弹。
- 摩擦轮下电逻辑正常：高速时先主动降速，低速后清 PID 和电流，直接清PID会让轮子一直转。
- 摩擦轮速度 F/G 调节、UI 显示、实际转速一致。
- 拨弹连发、单发、打符单发、自瞄触发射击都正常；卡弹自动反转能恢复，不会反复误触发。
- `shoot_flag`、弹速回传、剩余弹量提示和 UI 低弹量报警一致。

## 底盘功能

- 无超电情况下，底盘不超功率；裁判功率上限、缓冲能量低/高、裁判掉线三种情况都要测。
- 底盘功率预测和实际功率误差在 5 W 左右；重点看 `predict_send_power`、`now_power_predict`、超电实测功率。
- 功率削减后四个轮电流不出现 NaN、负比例或单轮异常清零；任意轮电机掉线时功控和发送安全。
- 超电在线、离线、电压过高异常、电量不足、按住 Shift 启用和松开退出都正常；无能量时不能给额外功率。
- 底盘速度上限随功率变化合理，35 W 节能模式下速度不为负，小陀螺和平移速度不会突然跳变。
- 跟随模式下底盘方向判断正确：正面/背面切换、最短角跟随、死区和软区无抖动。
- 过洞模式下不允许小陀螺：云台 `DOWN` 时按 C 不应进入 `CV_ROTATE`，松开后仍回到跟随。
- WASD 平移方向、底盘坐标变换、云台正反面控制方向都要测，避免电机 ID 或符号修改后方向反。
- 底盘下电/离线时，`set_x_v`、`set_y_v`、`set_yaw_v`、四轮电流、跟随前馈全部清零。

## 裁判系统与 UI

- 裁判系统正常接收，`Robot_ID_Current` 有效后 UI 能先清屏再加载静态图形。
- UI 正常绘制：准心、车道线、Pitch 动态车道线、云台模式、底盘模式、PC 状态、自瞄模式、摩擦轮速度、超电电压/电量条、低弹量报警、车头方向。
- UI 每 5 s 能自动重发静态内容，选手端清空 UI 后能恢复。
- 字符串长度固定后没有残影，长文字切短文字时能被空格覆盖。
- Pitch 改变时左右车道线同步移动，不抢占过多 0x0301 发送带宽。
- 裁判掉线/上线切换时，热量、功率上限、低弹量报警、云台侧裁判连接判断都一致。

## 改代码后的重点回归

- 改云台 PID/前馈：跑 Pitch/Yaw 阶跃、跟随、回正、自瞄进入退出、过洞前馈。
- 改升降：跑上升、下降、半路反向、反馈掉线、堵转、传感器异常、到位判定。
- 改底盘功控：跑无超电、开超电、裁判缓冲低、裁判掉线、单轮掉线、小陀螺和平移混合。
- 改通信结构体或 CAN ID：同时检查云台发底盘、底盘收云台、底盘发云台、云台收底盘四条链路。
- 改裁判/UI：检查接收解析、UI 首次 Add、动态 Change、5 s 重发、热量/功率数据联动。
- 改遥控/键鼠：检查 DT7、VT、键鼠三种入口的模式初始化、下电、比赛模式、检录模式和射击权限。
